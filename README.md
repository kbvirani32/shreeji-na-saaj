# ॥ શ્રી ગોપીજનવલ્લભાય નમઃ ॥
# શ્રીજી ના સાજ | श्रीजी ना साज | Shreeji Na Saaj
### ભગવાના વસ્ત્રો, સાજ ઓર્ડર અને નફો-નુકસાન મેનેજમેન્ટ એપ્લિકેશન (Mobile & PC App)

આ એપ્લિકેશન ખાસ કરીને **ભગવાનના વસ્ત્રો (ઠાકોરજી, શ્રીનાથજી, લાલન/લાડુ ગોપાલ, મહાપ્રભુજી, યમુનાજી વગેરે) અને સાજ** બનાવતા વ્યવસાય માટે તૈયાર કરવામાં આવી છે. તે **મોબાઇલ (Android અને iPhone/iOS)** તથા **કમ્પ્યુટર/લેપટોપ (PC)** બંનેમાં સરળતાથી ચાલે છે.

---

## 📱 ૧. મોબાઇલ વ્યુ અને એપ્લિકેશન ઇન્સ્ટોલેશન (Mobile View & Install App)

### 🌟 મોબાઇલ વ્યુ સુવિધાઓ (Mobile App Experience):
* **નેટિવ બોટમ નેવિગેશન બાર (Bottom Navigation Bar)**: Android અને iOS એપ્સ જેવો જ નીચે ફિક્સ બાર જેમાં:
  1. 📊 **ડેશબોર્ડ (Dashboard)**: કુલ ઓર્ડર્સ, કામ ચાલુ, પૂરા થયેલ અને ચોખ્ખો નફો.
  2. 🥻 **ઓર્ડર્સ (Orders)**: લાઇવ પેન્ડિંગ ઓર્ડર કાઉન્ટ બેજ સાથે.
  3. ➕ **નવો ઓર્ડર (Center Action)**: ગોલ્ડન સેન્ટ્રલ બટન ૧-ટેપમાં ઓર્ડર નોંધવા માટે.
  4. 💰 **નફો-નુકસાન (P&L)**: આવક અને ખર્ચનો હિસાબ.
  5. ☰ **મેનુ (More Drawer)**: ગ્રાહકો, કારીગરો, સેટિંગ્સ, CSV અને બેકઅપ.
* **હેડર રિસ્પોન્સિવ ઓપ્ટિમાઇઝેશન**: મોબાઇલ સ્ક્રીન પર વ્યવસ્થિત શ્રીનાથજી લોગો, ટાઇટલ, 📱 QR બટન, 🎨 થીમ બટન, 🔤 ફોન્ટ બટન અને `ગુ` / `म` / `EN` કોમ્પેક્ટ ભાષા સિલેક્ટર.
* **૧૦૦% શુદ્ધ વેક્ટર આઇકન્સ (SVG)**: કોઈ પણ ફોન્ટ ક્રેકીંગ કે ખાલી ચોરસ `□` બોક્સ નહીં.

### 📲 મોબાઇલ પર ઇન્સ્ટોલ કરવાની રીત (Step-by-Step):
1. કમ્પ્યુટર પર **`Start_Shreeji_Na_Saaj.bat`** ચાલુ કરો.
2. એપના હેડરમાં અથવા સેટિંગ્સમાં આપેલા **📱 મોબાઇલ ઇન્સ્ટોલ / QR Code** બટન પર ક્લિક કરો.
3. **Android યુઝર્સ (Google Chrome)**:
   * ફોનના કેમેરાથી સ્ક્રીન પરનો QR Code સ્કેન કરો (અથવા `http://192.168.3.135:8080/` ખોલો).
   * ક્રોમમાં ઉપર જમણી બાજુ **ત્રણ ટપકાં (⋮)** પર ટેપ કરો.
   * **"Install app" (એપ ઇન્સ્ટોલ કરો)** અથવા **"Add to Home screen" (હોમ સ્ક્રીન પર ઉમેરો)** દબાવો.
   * તમારા ફોનની હોમ સ્ક્રીન પર શ્રીનાથજીના આઇકન સાથે એપ આવી જશે અને ઇન્ટરનેટ વગર પણ ફૂલ સ્ક્રીન ચાલશે!
4. **iPhone / iPad યુઝર્સ (Safari)**:
   * Safari બ્રાઉઝરમાં લિંક ખોલો.
   * નીચે વચ્ચે રહેલા **Share બટન (ચોરસ અને ઉપર તીર ⎋)** પર ટેપ કરો.
   * નીચે સ્ક્રોલ કરી **"Add to Home Screen" (હોમ સ્ક્રીન પર ઉમેરો ➕)** પસંદ કરો અને "Add" દબાવો.
